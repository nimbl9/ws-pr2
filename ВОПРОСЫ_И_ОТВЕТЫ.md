# Ответы на контрольные вопросы — Практическая работа (Модуль 02)

## 1. Что такое Web API?
Web API (Web Application Programming Interface) — это программный интерфейс, доступный по протоколу HTTP, который позволяет различным клиентским приложениям (браузерам, мобильным клиентам, сторонним сервисам) взаимодействовать с сервером. В современной разработке Web API обычно строится по архитектурным принципам REST и обменивается данными в формате JSON или XML.

## 2. Для чего нужен ControllerBase?
`ControllerBase` — это базовый класс в ASP.NET Core для создания контроллеров Web API, которые не используют представления Razor (Views). Он предоставляет доступ к контексту HTTP-запроса (`HttpContext`, `Request`, `Response`, `User`), а также к вспомогательным методам формирования стандартных ответов (например, `Ok()`, `NotFound()`, `BadRequest()`, `CreatedAtAction()`). Наследование от `ControllerBase` снижает накладные расходы по сравнению с `Controller`, предназначенным для MVC с HTML-представлениями.

## 3. Что делает атрибут [ApiController]?
Атрибут `[ApiController]` применяется к классам контроллеров Web API и активирует ряд специализированных возможностей конвейера:
- **Автоматическая валидация модели**: если данные запроса не прошли валидацию, ASP.NET Core автоматически возвращает ответ с кодом `400 Bad Request` с описанием ошибок.
- **Автоматический вывод источников привязки**: параметры сложных типов связываются из тела запроса (`[FromBody]`), параметры простых типов — из маршрута (`[FromRoute]`) или строки запроса (`[FromQuery]`).
- **Форматирование ProblemDetails**: ошибки по умолчанию формируются в стандартизированном формате RFC 7807.
- **Требование явной маршрутизации по атрибутам**: гарантирует использование атрибута `[Route]`.

## 4. Для чего используется [Route]?
Атрибут `[Route]` используется для определения шаблона URL-маршрутизации (Attribute Routing), по которому конечные точки контроллера или отдельного метода будут сопоставляться с входящими HTTP-запросами. Например, `[Route("api/[controller]")]` заменяет маркер `[controller]` на имя класса контроллера без суффикса (для `StudentsController` маршрутом будет `/api/students`).

## 5. В чем разница между GET и POST?
- **GET**: предназначен для запроса и получения данных с сервера. Запрос GET является идемпотентным и безопасным (не должен изменять состояние сервера), передает параметры через строку запроса (Query String) и может кэшироваться браузерами и прокси-серверами.
- **POST**: предназначен для отправки данных на сервер с целью создания нового ресурса или выполнения операций, изменяющих состояние системы. Данные передаются в теле (Body) HTTP-запроса, метод не является идемпотентным и по умолчанию не кэшируется.

## 6. Что означает HTTP-код 404 Not Found?
Код состояния `404 Not Found` указывает на то, что запрашиваемый ресурс не был найден на сервере по указанному URL-адресу. В контексте REST Web API данный код обычно возвращается, если клиент запросил конкретный объект по идентификатору (например, `GET /api/students/999`), но сущность с таким ID в хранилище данных отсутствует.
